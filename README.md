# Smart-Expense-Splitter

A React + Vite application for splitting group expenses and tracking balances.

This project was initialized with the Vite React template and includes the app structure for an expense-sharing dashboard.

## Features

- Manage groups and members
- Add and list expenses
- View balances and summaries
- Dashboard UI for an expense-splitting workflow

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
